# Tshiluba - Republique Democratique du Congo

* **Code ISO 639-3** : `lua`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Kasai, Mbuji-Mayi, Kananga, Tshikapa

---

## Presentation & Caracteristiques

Langue tonale des peuples Luba du Kasai, d'une grande elegance poetique.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/congo_rdc/tshiluba/`).

### Format de nommage recommande :
```text
tshiluba_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `tshiluba_ville_h30_conte_01.mp3`
* `tshiluba_marche_f25_dialogue_02.ogg`
