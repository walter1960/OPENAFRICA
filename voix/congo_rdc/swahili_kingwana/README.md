# Swahili congolais (Kingwana) - Republique Democratique du Congo

* **Code ISO 639-3** : `swc`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Goma, Bukavu, Lubumbashi, Kisangani, Est

---

## Presentation & Caracteristiques

Variante congolaise du Swahili, moteur des echanges de tout l'Est de la RDC.
