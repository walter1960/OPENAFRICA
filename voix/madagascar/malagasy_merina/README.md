# Malagasy officiel (Merina) - Madagascar

* **Code ISO 639-3** : `plt`
* **Famille linguistique** : Austronesien / Malayo-Polynesien / Barito
* **Aire geographique** : Hautes Terres, Antananarivo, national

---

## Presentation & Caracteristiques

Base du malgache standard, poésie oratoire traditionnelle du Kabary.

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/madagascar/malagasy_merina/`).

### Format de nommage recommande :
```text
malagasy_merina_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `malagasy_merina_ville_h30_conte_01.mp3`
* `malagasy_merina_marche_f25_dialogue_02.ogg`
