# Nzema - Ghana

* **Code ISO 639-3** : `nzi`
* **Famille linguistique** : Niger-Congo / Kwa
* **Aire geographique** : Western Region, Axim, Half Assini

---

## Presentation & Caracteristiques

Langue de Kwame Nkrumah, frontaliere avec la Cote d'Ivoire.
