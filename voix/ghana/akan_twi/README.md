# Akan (Asante Twi, Akuapem, Fante) - Ghana

* **Code ISO 639-3** : `aka`
* **Famille linguistique** : Niger-Congo / Kwa
* **Aire geographique** : Kumasi, Ashanti, Central, Eastern

---

## Presentation & Caracteristiques

Langue la plus parlee du Ghana (>50% de la population). Langue tonale avec harmonie vocalique.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/ghana/akan_twi/`).

### Format de nommage recommande :
```text
akan_twi_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `akan_twi_ville_h30_conte_01.mp3`
* `akan_twi_marche_f25_dialogue_02.ogg`
