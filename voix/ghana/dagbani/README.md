# Dagbani - Ghana

* **Code ISO 639-3** : `dag`
* **Famille linguistique** : Niger-Congo / Gur
* **Aire geographique** : Northern Region, Tamale, Yendi

---

## Presentation & Caracteristiques

Langue du Royaume du Dagbon, dominante dans le Nord ghanéen.
