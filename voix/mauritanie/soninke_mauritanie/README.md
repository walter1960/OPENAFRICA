## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/mauritanie/soninke_mauritanie/`).

### Format de nommage recommande :
```text
soninke_mauritanie_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `soninke_mauritanie_ville_h30_conte_01.mp3`
* `soninke_mauritanie_marche_f25_dialogue_02.ogg`
