# Arabe Hassaniya - Mauritanie

* **Code ISO 639-3** : `mey`
* **Famille linguistique** : Afro-Asiatique / Semitique / Arabe
* **Aire geographique** : Nouakchott, Nouadhibou, Adrar, Trarza, Hodh

---

## Presentation & Caracteristiques

Variete dialectale arabe propre aux populations maures, a riche tradition poetique orale (Gueyzen).
