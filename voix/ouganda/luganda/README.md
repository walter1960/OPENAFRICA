# Luganda - Ouganda

* **Code ISO 639-3** : `lug`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Kampala, Buganda, Central Region

---

## Presentation & Caracteristiques

Langue la plus parlee du pays, tonale avec systeme d'accord strict.

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/ouganda/luganda/`).

### Format de nommage recommande :
```text
luganda_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `luganda_ville_h30_conte_01.mp3`
* `luganda_marche_f25_dialogue_02.ogg`
