# Arabe tunisien (Derja) - Tunisie

* **Code ISO 639-3** : `aeb`
* **Famille linguistique** : Afro-Asiatique / Semitique / Arabe
* **Aire geographique** : Tunis, Sfax, Sousse, Bizerte, Kairouan, national

---

## Presentation & Caracteristiques

Langue vernaculaire de plus de 12 millions de Tunisiens, basee sur le substrat punique et berbere.
