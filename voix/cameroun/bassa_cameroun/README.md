# Bassa - Cameroun

* **Code ISO 639-3** : `bas`
* **Famille linguistique** : Niger-Congo / Bantu (A40)
* **Aire geographique** : Littoral, Centre, Edea, Babimbi

---

## Presentation & Caracteristiques

Langue tonale celebre pour sa philosophie et sa tradition orale du Mbok.
