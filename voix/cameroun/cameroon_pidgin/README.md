# Cameroon Pidgin English (Kamtok) - Cameroun

* **Code ISO 639-3** : `wes`
* **Famille linguistique** : Creole a base anglaise
* **Aire geographique** : Nord-Ouest, Sud-Ouest, Douala, marches urbains

---

## Presentation & Caracteristiques

Lingua franca parlee par des millions de Camerounais francophones et anglophones.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/cameroun/cameroon_pidgin/`).

### Format de nommage recommande :
```text
cameroon_pidgin_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `cameroon_pidgin_ville_h30_conte_01.mp3`
* `cameroon_pidgin_marche_f25_dialogue_02.ogg`
