# Sesotho (Sotho du Sud) - Lesotho

* **Code ISO 639-3** : `sot`
* **Famille linguistique** : Niger-Congo / Bantu / Sotho-Tswana
* **Aire geographique** : Maseru, Thaba-Tseka, national

---

## Presentation & Caracteristiques

Langue nationale unificatrice parlee dans l'ensemble du royaume montagnard. Langue tonale avec clics adoptés des langues khoisan.
