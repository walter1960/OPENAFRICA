# Arabe marocain (Darija) - Maroc

* **Code ISO 639-3** : `ary`
* **Famille linguistique** : Afro-Asiatique / Semitique / Arabe
* **Aire geographique** : Casablanca, Rabat, Fes, Marrakech, Tanger, national

---

## Presentation & Caracteristiques

Lingua franca quotidienne parlee par plus de 90% des Marocains, tres riche en substrat berbere.
