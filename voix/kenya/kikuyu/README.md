# Kikuyu (Gikuyu) - Kenya

* **Code ISO 639-3** : `kik`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Central Kenya, Nyeri, Muranga, Nairobi

---

## Presentation & Caracteristiques

Langue du mont Kenya, tonale a deux tons, riche tradition d'epopees et de proverbes.
