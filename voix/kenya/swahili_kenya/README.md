# Kiswahili - Kenya

* **Code ISO 639-3** : `swh`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Mombasa, cote, Nairobi, national

---

## Presentation & Caracteristiques

Langue nationale et officielle, langue vehiculaire est-africaine par excellence.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/kenya/swahili_kenya/`).

### Format de nommage recommande :
```text
swahili_kenya_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `swahili_kenya_ville_h30_conte_01.mp3`
* `swahili_kenya_marche_f25_dialogue_02.ogg`
