# Luo (Dholuo) - Kenya

* **Code ISO 639-3** : `luo`
* **Famille linguistique** : Nilo-Saharien / Nilotique occidental
* **Aire geographique** : Kisumu, Lac Victoria, Nyanza

---

## Presentation & Caracteristiques

Grande langue nilotique tonale du bassin du Lac Victoria.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/kenya/luo/`).

### Format de nommage recommande :
```text
luo_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```

* `luo_ville_h30_conte_01.mp3`
* `luo_marche_f25_dialogue_02.ogg`
