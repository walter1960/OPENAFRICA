# Somali (Issa) - Djibouti

* **Code ISO 639-3** : `som`
* **Famille linguistique** : Afro-Asiatique / Couchitique
* **Aire geographique** : Djibouti-ville, Ali Sabieh, Dikhil

## Presentation & Caracteristiques

Langue de la majorite de la population, poésie orale de renommee mondiale.

