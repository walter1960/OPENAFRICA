# Siwi (Berbere de Siwa) - Egypte

* **Code ISO 639-3** : `siz`
* **Famille linguistique** : Afro-Asiatique / Berbere
* **Aire geographique** : Oasis de Siwa

---

## Presentation & Caracteristiques

L'enclave berberophone la plus orientale d'Afrique du Nord.

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/egypte/siwi/`).

### Format de nommage recommande :
```text
siwi_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `siwi_ville_h30_conte_01.mp3`
* `siwi_marche_f25_dialogue_02.ogg`
