# Nubien (Nobiin / Kenuzi-Dongola) - Egypte

* **Code ISO 639-3** : `fia`
* **Famille linguistique** : Nilo-Saharien / Nubien
* **Aire geographique** : Assouan, Nubie, rives du Nil

---

## Presentation & Caracteristiques

Langue millenaire des pharaons noirs et du Royaume de Koush.
