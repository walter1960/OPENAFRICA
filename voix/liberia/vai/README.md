# Vai - Liberia

* **Code ISO 639-3** : `vai`
* **Famille linguistique** : Niger-Congo / Mande
* **Aire geographique** : Grand Cape Mount, Robertsport

---

## Presentation & Caracteristiques

Langue mondialement celebre pour son syllabaire Vai invente au 19e siecle par Momolu Duwalu Bukele.
