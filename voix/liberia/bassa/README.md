# Bassa - Liberia

* **Code ISO 639-3** : `bsq`
* **Famille linguistique** : Niger-Congo / Krou
* **Aire geographique** : Grand Bassa, Buchanan, Rivercess

---

## Presentation & Caracteristiques

Langue krou cotiere ayant developpe son propre alphabet historique (alphabet Vah).
