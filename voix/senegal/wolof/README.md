# Wolof - Senegal

* **Code ISO 639-3** : `wol`
* **Famille linguistique** : Niger-Congo / Atlantique
* **Aire geographique** : Dakar, Thies, Saint-Louis, Diourbel, Kaolack

---

## Presentation & Caracteristiques

Langue nationale et vehiculaire universelle du Senegal, non tonale mais a prosodie rythmee.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/senegal/wolof/`).

### Format de nommage recommande :
```text
wolof_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `wolof_ville_h30_conte_01.mp3`
* `wolof_marche_f25_dialogue_02.ogg`
