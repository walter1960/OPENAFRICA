# Icibemba (Bemba) - Zambie

* **Code ISO 639-3** : `bem`
* **Famille linguistique** : Niger-Congo / Bantu (M40)
* **Aire geographique** : Copperbelt, Northern, Luapula, Lusaka

---

## Presentation & Caracteristiques

Langue la plus parlee de Zambie (~35-40%), moteur du bassin minier et urbain.
