# Chichewa (Chinyanja) - Malawi

* **Code ISO 639-3** : `nya`
* **Famille linguistique** : Niger-Congo / Bantu (N30)
* **Aire geographique** : Lilongwe, Blantyre, Zomba, Centre et Sud

---

## Presentation & Caracteristiques

Langue nationale et officielle du Malawi, tonale, langue des societes rituelles Gule Wamkulu.
