# Oromo (Afaan Oromoo) - Ethiopie

* **Code ISO 639-3** : `orm`
* **Famille linguistique** : Afro-Asiatique / Couchitique
* **Aire geographique** : Oromia, Adama, Jimma, Dire Dawa

---

## Presentation & Caracteristiques

Langue la plus parlee d'Ethiopie (~35% de la population), systeme tonal d'accent de hauteur.
