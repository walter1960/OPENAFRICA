# Mende - Sierra Leone

* **Code ISO 639-3** : `men`
* **Famille linguistique** : Niger-Congo / Mande
* **Aire geographique** : Southern Province, Bo, Kenema

---

## Presentation & Caracteristiques

Langue tonale majeure du Sud, syllabaire Kikakui historique.
