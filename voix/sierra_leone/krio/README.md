# Krio - Sierra Leone

* **Code ISO 639-3** : `kri`
* **Famille linguistique** : Creole a base anglaise et substrats ouest-africains
* **Aire geographique** : Freetown, Western Area, national

---

## Presentation & Caracteristiques

Lingua franca de plus de 90% des Sierra-Leonais, issue des Krios / esclaves affranchis.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/sierra_leone/krio/`).

### Format de nommage recommande :
```text
krio_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `krio_ville_h30_conte_01.mp3`
* `krio_marche_f25_dialogue_02.ogg`
