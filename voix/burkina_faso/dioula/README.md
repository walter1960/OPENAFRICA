# Dioula - Burkina Faso

* **Code ISO 639-3** : `dyu`
* **Famille linguistique** : Niger-Congo / Mande
* **Aire geographique** : Ouest, Bobo-Dioulasso, Banfora

---

## Presentation & Caracteristiques

Grande langue vehiculaire commerciale de l'Ouest burkinabe et de la sous-region.
