# Fulfulde (Peul du Burkina) - Burkina Faso

* **Code ISO 639-3** : `fuh`
* **Famille linguistique** : Niger-Congo / Atlantique
* **Aire geographique** : Sahel, Dori, Djibo

---

## Presentation & Caracteristiques

Parler pastoral sahélien avec riche vocabulaire lie a l'elevage et la transhumance.
