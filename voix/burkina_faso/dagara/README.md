# Dagara - Burkina Faso

* **Code ISO 639-3** : `dga`
* **Famille linguistique** : Niger-Congo / Gur
* **Aire geographique** : Sud-Ouest, Gaoua, Diebougou

---

## Presentation & Caracteristiques

Langue tonale des communautes Dagara a la frontiere du Ghana.

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/burkina_faso/dagara/`).

### Format de nommage recommande :
```text
dagara_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `dagara_ville_h30_conte_01.mp3`
* `dagara_marche_f25_dialogue_02.ogg`
