# Tamasheq (Tamasheɣt / Touareg) - Mali

* **Code ISO 639-3** : `taq`
* **Famille linguistique** : Afro-Asiatique $\rightarrow$ Berbère $\rightarrow$ Berbère méridional (Touareg)
* **Locuteurs au Mali** : ~600 000
* **Aire géographique** : Kidal, Ménaka, Gao, Tombouctou, Adrar des Ifoghas, Azawad.

---

## Variétés & Écriture

Le Tamasheq est la langue des **Kel Tamasheq** (le peuple touareg).
* **Écriture ancestrale** : Le **Tifinagh** (alphabet libyco-berbère plurimillénaire) gravé sur les roches du Sahara.
* **Variétés** :
  * *Tadghaq* (Kidal, Adrar des Ifoghas).
  * *Kal Ansar / Tombouctou*.
  * *Ménaka / Iullemmeden*.
* **Caractéristiques phonétiques** : Langue consonantique riche, pharyngalisée, à forte racine trilitère, non tonale (accent d'intensité et de durée).
