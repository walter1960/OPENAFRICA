# Gambie - Patrimoine Vocal

Enclavee le long du fleuve Gambie, la Gambie partage ses langues principales avec le Senegal voisin : Mandinka, Wolof et Fula.

---

## Langues du Gambie dans ce Depot

| :--- | :--- | :--- | :--- | :--- |
| **Mandinka** | `mnk` | Niger-Congo / Mande | Banjul, Brikama, le long du fleuve | [Accéder à `mandinka/`](mandinka/README.md) |
| **Wolof gambien** | `wol` | Niger-Congo / Atlantique | Banjul, Serrekunda, Kanifing | [Accéder à `wolof/`](wolof/README.md) |

## Priorites de Collecte pour le Gambie

1. **Emissions radiophoniques locales** : Journaux parles, debats communautaires, tribunes interactives.
2. **Notes vocales de la vie quotidienne** : Echanges sur les marches, transports, discussions familiales spontanees.
3. **Oralite traditionnelle** : Contes oraux, proverbes, recits des anciens et chants traditionnels.
