# Jola (Diola) - Gambie

* **Code ISO 639-3** : `dyo`
* **Famille linguistique** : Niger-Congo / Atlantique
* **Aire geographique** : Western Division, Foni

---

## Presentation & Caracteristiques

Langue des riziculteurs de la vallee de Casamance et Gambie.
