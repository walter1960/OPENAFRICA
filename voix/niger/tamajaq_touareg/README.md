# Tamajaq (Touareg du Niger) - Niger

* **Code ISO 639-3** : `ttq`
* **Famille linguistique** : Afro-Asiatique / Berbere
* **Aire geographique** : Agadez, Air, Azawak, Tahoua

---

## Presentation & Caracteristiques

Langue des nomades Kel Tamajaq du Sahara nigerien, ecriture Tifinagh.
