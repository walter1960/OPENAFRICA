# Hausa - Niger

* **Code ISO 639-3** : `hau`
* **Famille linguistique** : Afro-Asiatique / Tchadique
* **Aire geographique** : Maradi, Zinder, Tahoua, Dosso

---

## Presentation & Caracteristiques

Langue majoritaire (>55% de la population nigerienne), tonale (haut, bas, descendant).
