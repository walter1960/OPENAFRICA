# Zarma (Djerma) - Niger

* **Code ISO 639-3** : `dje`
* **Famille linguistique** : Nilo-Saharien / Songhai
* **Aire geographique** : Niamey, Dosso, Tillaberi

---

## Presentation & Caracteristiques

Deuxieme langue du pays (~22%), langue historique des guerriers Zarma le long du Niger.
