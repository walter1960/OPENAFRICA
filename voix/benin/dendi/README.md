# Dendi - Bénin

* **Code ISO 639-3** : `ddn`
* **Famille linguistique** : Nilo-Saharien $\rightarrow$ Songhaï méridional
* **Locuteurs au Bénin** : ~400 000
* **Aire géographique** : Djougou, Parakou, Malanville, Kandi, Karimama (le long du fleuve Niger).

---

## Variétés & Importance Historique

Le Dendi est issu de l'expansion de l'Empire Songhaï vers le Sud le long du fleuve Niger après la chute de Gao (1591).
Il est devenu la **lingua franca marchande** des grands marchés caravaniers du Nord Bénin (notamment à Djougou).

* **Système tonal** : Langue tonale avec des distinctions haut/bas.
* **Vocabulaire commercial et islamique** : Très présent dans les négociations sur les marchés et le négoce transsaharien (Nigéria, Niger, Togo).
