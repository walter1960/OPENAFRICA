# Balanta - Guinee-Bissau

* **Code ISO 639-3** : `ble`
* **Famille linguistique** : Niger-Congo / Atlantique / Bak
* **Aire geographique** : Oio, Tombali, Quinara

---

## Presentation & Caracteristiques

Langue de l'ethnie la plus nombreuse, celebre pour ses societes sans Etat traditionnel et sa riziculture.
