# chiShona (Shona) - Zimbabwe

* **Code ISO 639-3** : `sna`
* **Famille linguistique** : Niger-Congo / Bantu (S10)
* **Aire geographique** : Harare, Mashonaland, Manicaland, Masvingo

---

## Presentation & Caracteristiques

Langue de la majorite des Zimbabweenes, heritiers de la civilisation du Grand Zimbabwe, tonale (haut, bas), proverbes Tsumo.
