# isiNdebele du Zimbabwe - Zimbabwe

* **Code ISO 639-3** : `nde`
* **Famille linguistique** : Niger-Congo / Bantu / Nguni
* **Aire geographique** : Matabeleland, Bulawayo

---

## Presentation & Caracteristiques

Langue nguni historique fondee par le roi Mzilikazi, clics consonantiques.
