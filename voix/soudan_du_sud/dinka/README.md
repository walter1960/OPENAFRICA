# Dinka (Thuongjang) - Soudan du Sud

* **Code ISO 639-3** : `din`
* **Famille linguistique** : Nilo-Saharien / Nilotique
* **Aire geographique** : Bahr el Ghazal, Jonglei, Rumbek

---

## Presentation & Caracteristiques

Langue du plus grand groupe ethnique, pastorale, tonale (avec degres de voix soufflee et craquee).

---
