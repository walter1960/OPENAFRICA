# Nuer (Thok Naath) - Soudan du Sud

* **Code ISO 639-3** : `nus`
* **Famille linguistique** : Nilo-Saharien / Nilotique
* **Aire geographique** : Haut-Nil, Bentiu, Nasir

---

## Presentation & Caracteristiques

Langue pastorale des berges du Nil Blanc.
