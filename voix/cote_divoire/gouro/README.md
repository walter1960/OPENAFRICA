# Gouro - Cote d'Ivoire

* **Code ISO 639-3** : `goa`
* **Famille linguistique** : Niger-Congo / Mande
* **Aire geographique** : Centre-Ouest, Bouafle, Zuenoula

---

## Presentation & Caracteristiques

Langue de la danse Zaouli, riche tradition orale.
