# Baoule - Cote d'Ivoire

* **Code ISO 639-3** : `bci`
* **Famille linguistique** : Niger-Congo / Kwa
* **Aire geographique** : Centre, Bouake, Yamoussoukro

---

## Presentation & Caracteristiques

Langue akan majeure de Cote d'Ivoire, tonale (trois tons cardinaux).
