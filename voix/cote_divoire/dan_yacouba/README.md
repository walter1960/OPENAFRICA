# Dan (Yacouba) - Cote d'Ivoire

* **Code ISO 639-3** : `daf`
* **Famille linguistique** : Niger-Congo / Mande
* **Aire geographique** : Ouest montagneux, Man, Danane

---

## Presentation & Caracteristiques

Langue montagnarde celebre pour son inventaire tonal extreme (jusqu'a 5 tons distincts).
