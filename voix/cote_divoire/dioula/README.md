# Dioula - Cote d'Ivoire

* **Code ISO 639-3** : `dyu`
* **Famille linguistique** : Niger-Congo / Mande
* **Aire geographique** : Nord, Abidjan et marche national

---

## Presentation & Caracteristiques

Lingua franca du commerce ivoirien, parlee sur tous les marches.
