# Bete - Cote d'Ivoire

* **Code ISO 639-3** : `bet`
* **Famille linguistique** : Niger-Congo / Krou
* **Aire geographique** : Centre-Ouest, Gagnoa, Daloa, Soubre

---

## Presentation & Caracteristiques

Langue krou a systeme tonal complexe (jusqu'a 4 hauteurs tonales).

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/cote_divoire/bete/`).

### Format de nommage recommande :
```text
bete_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `bete_ville_h30_conte_01.mp3`
* `bete_marche_f25_dialogue_02.ogg`
