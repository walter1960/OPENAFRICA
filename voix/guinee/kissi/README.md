## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/guinee/kissi/`).

```text
kissi_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
