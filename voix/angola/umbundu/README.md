# Umbundu (Mbundu du Sud) - Angola

* **Code ISO 639-3** : `umb`
* **Famille linguistique** : Niger-Congo / Bantu (R10)
* **Aire geographique** : Hauts plateaux centraux, Huambo, Benguela, Bie

---

## Presentation & Caracteristiques

Langue autochtone la plus parlee d'Angola (~35% de la population).
