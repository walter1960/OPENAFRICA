# Sango - Republique Centrafricaine

* **Code ISO 639-3** : `sag`
* **Famille linguistique** : Creole / Vehiculaire a base ngbandi
* **Aire geographique** : Bangui, national

---

## Presentation & Caracteristiques

Langue nationale et officielle, comprise et parlee dans tout le pays, tonale.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/centrafrique/sango/`).

### Format de nommage recommande :
```text
sango_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `sango_ville_h30_conte_01.mp3`
* `sango_marche_f25_dialogue_02.ogg`
