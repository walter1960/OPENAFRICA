* **Famille linguistique** : Niger-Congo / Oubanguien
* **Aire geographique** : Berberati, Bouar, Ouest

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/centrafrique/gbaya/`).

### Format de nommage recommande :
```text
gbaya_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `gbaya_ville_h30_conte_01.mp3`
* `gbaya_marche_f25_dialogue_02.ogg`
