## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/centrafrique/banda/`).

### Format de nommage recommande :
```text
banda_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `banda_ville_h30_conte_01.mp3`
* `banda_marche_f25_dialogue_02.ogg`
