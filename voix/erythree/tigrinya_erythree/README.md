# Tigrinya - Erythree

* **Code ISO 639-3** : `tir`
* **Famille linguistique** : Afro-Asiatique / Semitique ethiopien
* **Aire geographique** : Asmara, hauts plateaux

---

## Presentation & Caracteristiques

Langue utilisee avec l'alphabet Geez, tonale avec alternance de registre.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/erythree/tigrinya_erythree/`).

### Format de nommage recommande :
```text
tigrinya_erythree_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `tigrinya_erythree_ville_h30_conte_01.mp3`
* `tigrinya_erythree_marche_f25_dialogue_02.ogg`
