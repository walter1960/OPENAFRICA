# Beja (Bedawiyet) - Soudan

* **Code ISO 639-3** : `bej`
* **Famille linguistique** : Afro-Asiatique / Couchitique
* **Aire geographique** : Port-Soudan, Kassala, collines de la mer Rouge

---

## Presentation & Caracteristiques

Seule langue de la branche couchitique du Nord, parlee par les nomades Beja depuis l'Antiquite.

---
