# Hausa - Nigeria

* **Code ISO 639-3** : `hau`
* **Famille linguistique** : Afro-Asiatique / Tchadique
* **Aire geographique** : Kano, Kaduna, Sokoto, Katsina, Nord

---

## Presentation & Caracteristiques

La plus grande langue afro-asiatique subsaharienne, langue commerciale majeure de toute l'Afrique de l'Ouest.

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/nigeria/hausa_nigeria/`).

### Format de nommage recommande :
```text
hausa_nigeria_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `hausa_nigeria_ville_h30_conte_01.mp3`
* `hausa_nigeria_marche_f25_dialogue_02.ogg`
