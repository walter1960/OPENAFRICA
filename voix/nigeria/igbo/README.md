# Igbo - Nigeria

* **Code ISO 639-3** : `ibo`
* **Famille linguistique** : Niger-Congo / Volta-Niger
* **Aire geographique** : Enugu, Owerri, Onitsha, Aba, Sud-Est

---

## Presentation & Caracteristiques

Langue tonale majeure du Sud-Est nigerien, celebre pour ses proverbes et son ingeniosite commerciale.
