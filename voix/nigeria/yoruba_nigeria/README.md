# Yoruba - Nigeria

* **Code ISO 639-3** : `yor`
* **Famille linguistique** : Niger-Congo / Volta-Niger
* **Aire geographique** : Lagos, Ibadan, Oyo, Ogun, Ondo, Osun, Kwara

---

## Presentation & Caracteristiques

L'un des systemes tonals les plus etudies (3 tons distincts), riche tradition ifa et oriki.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/nigeria/yoruba_nigeria/`).

### Format de nommage recommande :
```text
yoruba_nigeria_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `yoruba_nigeria_ville_h30_conte_01.mp3`
* `yoruba_nigeria_marche_f25_dialogue_02.ogg`
