## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/nigeria/ibibio/`).

### Format de nommage recommande :
```text
ibibio_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `ibibio_ville_h30_conte_01.mp3`
* `ibibio_marche_f25_dialogue_02.ogg`
