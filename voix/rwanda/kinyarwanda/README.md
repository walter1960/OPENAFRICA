# Kinyarwanda - Rwanda

* **Code ISO 639-3** : `kin`
* **Famille linguistique** : Niger-Congo / Bantu (JD60)
* **Aire geographique** : Kigali, national

---

## Presentation & Caracteristiques

Langue nationale et officielle parlee par tous les Rwandais. Langue tonale avec systeme sophistique de classes nominales et art oratoire ancestral (Ibisigo).

---
