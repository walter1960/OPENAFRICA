# Emakhuwa (Makhuwa) - Mozambique

* **Code ISO 639-3** : `vmw`
* **Famille linguistique** : Niger-Congo / Bantu (P30)
* **Aire geographique** : Nampula, Cabo Delgado, Niassa, Zambezia

---

## Presentation & Caracteristiques

Langue la plus parlee du Mozambique (>25% de la population), tonale.
