# Fang - Gabon

* **Code ISO 639-3** : `fan`
* **Famille linguistique** : Niger-Congo / Bantu (A70)
* **Aire geographique** : Estuaire, Libreville, Woleu-Ntem, Moyen-Ogooue

---

## Presentation & Caracteristiques

Langue la plus parlee du Gabon (~35-40%), tradition de l'epopee du Mvet.
