# Punu (Yipunu) - Gabon

* **Code ISO 639-3** : `puu`
* **Famille linguistique** : Niger-Congo / Bantu (B40)
* **Aire geographique** : Ngounie, Mouila, Tchibanga

---

## Presentation & Caracteristiques

Langue des celebres masques blancs punu de l'Okuyi.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/gabon/punu/`).

### Format de nommage recommande :
```text
punu_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `punu_ville_h30_conte_01.mp3`
* `punu_marche_f25_dialogue_02.ogg`
