# Somali (Maxaatiri) - Somalie

* **Code ISO 639-3** : `som`
* **Famille linguistique** : Afro-Asiatique / Couchitique
* **Aire geographique** : Mogadiscio, Hargeisa, national

---

## Presentation & Caracteristiques

Variete standard et litteraire, langue tonale a accent de hauteur.

---

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/somalie/somali_standard/`).

### Format de nommage recommande :
```text
somali_standard_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `somali_standard_ville_h30_conte_01.mp3`
* `somali_standard_marche_f25_dialogue_02.ogg`
