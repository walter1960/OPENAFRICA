# Chagga (Kichagga) - Tanzanie

* **Code ISO 639-3** : `chg`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Kilimandjaro, Moshi

---

## Presentation & Caracteristiques

Langue des versants fertiles du mont Kilimandjaro.

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/tanzanie/chagga/`).

chagga_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
