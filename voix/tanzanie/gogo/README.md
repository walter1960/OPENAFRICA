# Gogo (Cigogo) - Tanzanie

* **Code ISO 639-3** : `gog`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Dodoma, plateau central

Langue de la region de la capitale administrative, celebre pour ses polyphonies vocales.
