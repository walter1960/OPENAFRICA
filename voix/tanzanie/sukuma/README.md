# Sukuma - Tanzanie

* **Code ISO 639-3** : `suk`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Mwanza, Shinyanga, Sud du Lac Victoria

---

## Presentation & Caracteristiques

Langue de la premiere ethnie de Tanzanie (~16% de la population), tonale.
