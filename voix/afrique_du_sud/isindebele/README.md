# isiNdebele - Afrique du Sud

* **Code ISO 639-3** : `nbl`
* **Famille linguistique** : Niger-Congo / Bantu / Nguni
* **Aire geographique** : Mpumalanga, Gauteng

---

## Presentation & Caracteristiques

Celebre pour l'art pictural geometrique mural des femmes Ndebele.

## Depot des Enregistrements

Deposez vos fichiers audio (`.mp3`, `.wav`, `.ogg`, `.m4a`) directement dans ce dossier (`voix/afrique_du_sud/isindebele/`).

### Format de nommage recommande :
```text
isindebele_[VILLE]_[GENRE_AGE]_[SUJET]_[INDEX].[ext]
```
Exemple :
* `isindebele_ville_h30_conte_01.mp3`
* `isindebele_marche_f25_dialogue_02.ogg`
