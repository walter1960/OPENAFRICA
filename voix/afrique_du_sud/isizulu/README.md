# isiZulu (Zoulou) - Afrique du Sud

* **Code ISO 639-3** : `zul`
* **Famille linguistique** : Niger-Congo / Bantu / Nguni
* **Aire geographique** : KwaZulu-Natal, Johannesburg, Gauteng

## Presentation & Caracteristiques

Langue maternelle la plus parlee du pays (~25%), langue tonale a clics consonantiques.
