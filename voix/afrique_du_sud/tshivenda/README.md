# Tshivenda - Afrique du Sud

* **Code ISO 639-3** : `ven`
* **Famille linguistique** : Niger-Congo / Bantu
* **Aire geographique** : Limpopo, Thohoyandou

---

## Presentation & Caracteristiques

Langue du peuple Venda aux traditions sacrees du lac Fundudzi.
