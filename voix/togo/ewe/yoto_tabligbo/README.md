# Yoto / Tabligbo - Ewe du Togo

* **Prefecture** : Yoto
* **Villes et localites principales** : Tabligbo, Tokpli, Ahepe, Kouve
* **Langue mere** : Ewe (Evegbé) - Code ISO 639-3 : `ewe`

---

## Particularites et Contexte

Variete du bassin calcaire et du fleuve Mono. Zone d'echanges intenses entre l'ewe, l'ouatchi et l'adja.
