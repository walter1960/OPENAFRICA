# Ave / Keve - Ewe du Togo

* **Prefecture** : Ave
* **Villes et localites principales** : Keve, Assahoun, Noepe, Andome
* **Langue mere** : Ewe (Evegbé) - Code ISO 639-3 : `ewe`

---

## Particularites et Contexte

Variete occidentale frontaliere avec la Volta Region du Ghana. Transition linguistique fluide avec les parlers ewe ghaneens.
