# Notse / Agbogbome (Gbengbe) - Ewe du Togo

* **Prefecture** : Haho
* **Villes et localites principales** : Notse, Wahala, Asrama, Kpelen
* **Langue mere** : Ewe (Evegbé) - Code ISO 639-3 : `ewe`

---

## Particularites et Contexte

Berceau historique ancestral de la migration de tout le peuple ewe (vestiges du mur d'Agbogbome). Variete prestigieuse, noble, riche en tournures archaiques, proverbes (lododo) et recits ceremoniels.
