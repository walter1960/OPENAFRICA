# Agou - Ewe du Togo

* **Prefecture** : Agou
* **Villes et localites principales** : Agou-Gadzepe, Adeta, Agou-Kebo, Mont Agou
* **Langue mere** : Ewe (Evegbé) - Code ISO 639-3 : `ewe`

---

## Particularites et Contexte

Parler des contreforts et versants du Mont Agou (point culminant du Togo). Intonations montagnardes specifiques et vocabulaire traditionnel arboricole.

---
