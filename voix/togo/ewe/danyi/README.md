# Danyi - Ewe du Togo

* **Prefecture** : Danyi
* **Villes et localites principales** : Danyi-Apeyeme, Danyi-Atigba, Danyi-Kavou
* **Langue mere** : Ewe (Evegbé) - Code ISO 639-3 : `ewe`

---

## Particularites et Contexte

Variete du plateau d'altitude de Danyi. Cadre geographique frais et isole ayant favorise la preservation d'expressions et de structures morphologiques anciennes.
