# Vo / Vogan (Ouatchi / Waci) - Ewe du Togo

* **Prefecture** : Vo
* **Villes et localites principales** : Vogan, Togoville, Mome-Hounkpati, Sevagan
* **Langue mere** : Ewe (Evegbé) - Code ISO 639-3 : `ewe`

---

## Particularites et Contexte

Variete Ouatchi (Wacigbe) du Sud-Est togolais. Branche du continuum Gbe tres proche de l'ewe avec des traits morphologiques et d'intonation bien individualises.
